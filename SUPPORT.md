# Support

Start with the [README](README.md), [build instructions](README.md#build), [scene controls](demos/infinity/README.md) and [music guide](docs/MUSIC_AND_BEATS.md).

For a bug, open a [GitHub issue](https://github.com/djayuffe/demo-engine/issues) with your OS, GPU/driver, build configuration, exact launch command, expected result and actual result. Include console logs and a screenshot where useful; remove private paths and personal information first.

For a new effect or engine feature, describe the visual goal, target hardware and acceptable render budget. Include original references and attribution for supplied assets.

This is an experimental graphics project. Physical Windows hardware and other GPU families may behave differently from the development Mac; reports with reproducible settings help close those gaps.
