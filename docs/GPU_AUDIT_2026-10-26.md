# GPU math audit — 26 October 2026

This pass reviews the native cosmic shaders, shared post/background/depth shader math, wire tessellation/expansion, bloom pyramid, Atlas geometry helpers and GPU query scheduling. It fixes demonstrated issues; it is not a proof of every renderer, an unrestricted physical simulation, or a guarantee across all drivers.

## Corrections

### Möbius normals

The surface previously evaluated its position at four neighbours in addition to the current vertex. Analytic partials now share the position trigonometry. The derivatives include both the ribbon twist and the animated multiplicative detail scale. This removes four complete surface evaluations per vertex and avoids finite-difference normal approximation. Actual frame-time gains depend on the scene's fragment and particle workload; no blanket speedup is claimed.

### Continuous cosmic noise

Six of the eight corner hash arguments used inconsistent second coordinates. Adjacent cells could disagree on the shared boundary. Every lattice index now maps to the same hash pair `(n,n+1)`. Procedural turbulence consequently changes appearance; this is an intentional continuity correction.

### Black-hole volume and jets

For a homogeneous ray segment, opacity is `1-exp(-tau)` with `tau=density*distance*0.34`. A fourth-order polynomial avoids cancellation for tiny optical depths and replaces a per-segment exponential; under the shader's bounds `tau<=0.0357`, its absolute truncation error is below 5e-10 before floating-point rounding. Emission uses this opacity and the same transmission update.

Jet emission is nonnegative and scales by travelled distance, preserving the former coefficient at the maximum 0.105 step. This removes step-count-dependent brightness. Reusing the existing projected radius avoids a duplicate projection and square root. Escape tests use squared radius. The renderer remains a bounded artistic curved-ray model, not a general-relativistic solver.

### Defined shader domains

GLSL powers of negative bases are undefined even when the exponent is written as 2. Signed Gaussian/ring terms now use multiplication. Descending smoothstep calls in native background and depth effects now use `1-smoothstep(low,high,x)` with ordered bounds. These changes preserve the intended mathematical shapes without relying on driver-specific behavior.

## Validation

`gpu_cosmic_tests` renders production GLSL math into a 32-bit floating-point target. It checks 512 parameter combinations against independent original position equations and central-difference derivatives, checks nondegenerate normals, and approaches positive/negative noise-cell boundaries on all axes. The existing GPU smoke tool invokes it alongside deformation comparisons and finite HDR checks for all 31 scenes.

```sh
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/gpu_cosmic_tests
python3 tools/gpu_smoke.py --build build
```

Native validation uses Apple M1 Pro, OpenGL 4.1 over Metal. Physical Windows/Linux GPU behavior remains to be verified. Imported reference snapshots are unchanged. Shared filter reconstruction retains its half-float headroom and 0.5 upsample weights; asynchronous query polling remains nonblocking. Near-plane tessellation and optical integration remain areas for broader device/trajectory testing rather than claims of complete correctness.
